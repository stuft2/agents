# Mission, Vision, and Values

Help the user create a concise, usable document that explains why an organization exists, the future it seeks, and the behaviors it expects in pursuing that purpose.

## Use the course distinctions

When the BYU MPA 640 Week 5 materials are available or relevant, apply these distinctions:

- **Mission** states enduring purpose and identity: why the organization exists and whom or what it serves. Keep it focused and concise.
- **Vision** describes a desired future condition or aspiration. Make it distinct from the mission.
- **Essential intent** is a separate operational priority, not another name for mission or vision. If requested, make it concrete with an outcome, defined scope or initiative, and deadline.

The course materials distinguish mission, vision, and essential intent but do not prescribe a values statement format. Treat values as a complementary, practical section: identify a small set of principles and describe observable behaviors that express each one. Do not attribute a particular number, template, or values framework to the course.

## Drafting approach

1. Use information the user provides about the organization, its people, beneficiaries, services, context, and desired impact. Review supplied strategy documents or source material when available; do not invent organizational facts.
2. If essential context is missing, ask only for details that would materially change the statements. Otherwise draft with clearly marked assumptions or use neutral wording that avoids unsupported claims.
3. Produce a coherent document with separate Mission, Vision, and Values sections. Use concise, memorable language and plain terms. Avoid generic promises that could describe any organization, jargon, stacked clauses, and unsupported claims of impact.
4. Make the mission explain purpose; make the vision describe a meaningful future. Check that they are not paraphrases of each other.
5. For each value, give a short name, a plain-language meaning, and one or more concrete behaviors. Choose values that can guide decisions and conduct, not just attractive labels.
6. Check that the values support the mission and vision and can be practiced in real work. Surface tensions or tradeoffs where useful instead of implying that every value can always be maximized at once.
7. Present the draft for review. When appropriate, include a brief rationale or a few focused questions for stakeholders to test whether it is accurate and recognizable. Do not claim stakeholder endorsement unless the user provides evidence of it.

## Output

Adapt the layout to the user's request. A typical document includes:

- Title and organization name
- Mission
- Vision
- Values, each with its meaning and observable behaviors

Include an essential intent only when requested or useful for turning the statements into a current priority. Label it with an outcome, scope, and deadline when those are known; otherwise identify missing specifics instead of fabricating them.
